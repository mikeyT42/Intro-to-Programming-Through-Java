Introduction:


This program will be practice with using enumerations, arrays, strings, and objects.

You will be writing a program that is going to be a "Library."  You will have some books that you will define, and print them all out.

Genre Enumeration:

This will be an enum that you will define that will represent book genres. Here are the values:

FICTION
NON_FICTION
SCIENCE_FICTION
MYSTERY
BIOGRAPHY

These values will then be used to print the kinds of genres. Put this enumeration inside of the Book class.

Book Class:

We need a string called title. Then declare a string called author. Declare another data member with a type of int called year. Then declare another data member with a type of Genre called genre. Finally, make the constructor for this class. Be sure to assign each input variable to their respective class member variable.

void printBook(Book book):

This function will be solely responsible for printing its given book argument. Make the argument final too. I want the printed output to look like the below:

book {
  title = The War of the Worlds
  author = H. G. Wells
  year = 1898
  genre = Science Fiction
}

It is possible to use a single printf statement to do this, but you can also do this in about 6 println statements. Be sure to make use of the toString() method on the Genre enum.

Main:

After the salutation, declare and initialize a Book array with 6 books. Initialize it with any 6 books that you like. Then, println this message:

Our library has ___ book(s).

Be sure to put 1 newline at the end. Give the length of the array in this println statement. Then call the printBook function for each book in our library array.

Conclusion:

Be sure to follow our formatting rules. Between function definitions put our function separator comment. Also, remember our variables and function names are following camel case. Be sure that indenting is proper as well. 4 spaces indentation, and no more than 100 characters wide.
